# Battles2AutoSender
 This program allows you to send bloons automatically without the use of the Bloon Bot.
 to use this program, download the Battles2_Auto_sender folder, the main program is main.exe which you will find in the main programs folder.

 for ease of use I would recommend creating a shortcut of the main program and put it wherever you want, you can even change the shortcut icon to the Battles2 logo with the icon.ico file in the important files folder.

 IMPORTANT : DO NOT MOVE ANY FILE FROM ITS ORIGINAL PLACE, IF YOU WANT TO PUT SOMETHING SOMEWHERE ELSE, CREATE A SHORTCUT OF THE FILE.

 how to use the program : when you run main.exe, the game will automatically open for you (if not, check the path in the Variables.txt in the important files folder). From there you can play the game normally, and note that the bloon will be sent automatically when you press the key. to send a different bloon, press right click (you might need to hold it for a second) to stop the auto-send, send a different bloon to have the program automatically send it.
